# CRYSTAL

**Codename:** Crystal

An independent smart-contract security research engine.

Crystal's differentiator is not the number of vulnerability signatures.
It is the ability to reason across:

`functions + state + data flow + protocol semantics + sequences + economics`

Crystal is designed to work alongside Slither, Aderyn, Foundry, Echidna,
Medusa, Halmos and other security tooling.

Arcadia remains a separate project. Crystal can later be consumed by Arcadia
as an external research engine.
